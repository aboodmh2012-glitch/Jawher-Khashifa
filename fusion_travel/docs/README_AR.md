# ملخص النسخة الموحّدة — Fusion Travel 19.0.2.4.0

هذه النسخة هي تحديث وإصلاح لنفس موديول `fusion_travel` الحالي، وليست موديولًا منفصلًا. حافظت على نماذج التذاكر وشركات الطيران والحقول ومعرّفات XML القديمة، ثم أضافت الحجوزات والواجهة والبوابة والتكاملات بصورة موحّدة.

## أهم الإصلاحات

- إغلاق عمليات `sudo` العامة وتحويل مسارات الموقع إلى دوال داخلية خاصة مع التحقق من مالك الحجز.
- فصل صلاحيات المستخدم والمحاسب والمدير وتقييد السجلات حسب الشركة والوكيل/العميل.
- منع تغيير السعر والعرض وحالة الدفع ومرجع المورد مباشرة عبر RPC.
- قفل هوية الحجز والمسافرين والمسارات بعد بدء الدفع أو معالجة المورد.
- تحويل Amadeus إلى REST مباشر مع OAuth وTimeout وتسجيل آمن بعد أرشفة SDK التاريخي.
- منع إعادة إرسال حجز نتيجته غير مؤكدة، ووضعه في `Needs Review`.
- إنشاء تسوية محاسبية فعلية لدفع المحفظة وربطها بفاتورة العميل.
- منع حذف القيود المرحلة أو إلغاء الحجز المدفوع بتغيير الحالة فقط.
- توزيع سعر المورد والـMarkup على كل مسافر بدقة العملة.
- تصحيح حسابات الاسترجاع والـVoid ومنع عمولة المورد من تجاوز إجمالي المورد.
- إضافة فحوص توافق الشركة والعميل والعملة بين الحجز والفاتورة والتذكرة.

## غير مكتمل قبل الإنتاج

- تجربة تثبيت وترقية حقيقية على نسخة قاعدة بيانات Odoo 19.
- اختبار Amadeus/consolidator الفعلي وإصدار أرقام التذاكر.
- ربط دفع مستضاف PCI مع callback موقّع.
- Queue/Outbox أو reconciliation worker للطلبات الخارجية عالية الحساسية.
- Rate limiting على مستوى البنية التحتية للمسارات العامة.
- مراجعة Pixel-by-Pixel لجميع شاشات Figma وحالات الهاتف.
